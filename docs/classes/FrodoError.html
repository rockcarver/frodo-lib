    The stable identity of the condition this error reports, if it has one. It is stable across releases, unlike the message. An error that wraps another FrodoError does not copy its code: look through originalErrors for the condition underneath. The one exception is a request that failed because of its proxy: the error of the request carries proxyFailure, and the FrodoError that wraps it is given that failure's code.

    OptionalrateLimit

    rateLimit?: LogApiRateLimit

    The state of the rate limit of the Log API, on the error that reports a request the API rejected with 429 (code LOG_API_RATE_LIMITED), if the answer carried the X-RateLimit-* headers. Like code, it is not copied by an error that wraps this one.
