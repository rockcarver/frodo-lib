    mergeDeep

    • mergeDeep(obj1: any, obj2: any): any

      Deep merge the second object into the first. The first object is changed and returned. A first argument that is null, undefined or otherwise falsy is returned as it is; a first argument that is truthy and not an object, a frozen first object and a property of the first object that has only a getter throw a TypeError. A second argument that is null, undefined or not an object changes nothing. Every own enumerable string key of the second object is applied to the first object, except the key proto, which is never copied (symbol keys are ignored). Two arrays are merged by index, and the first array is never shortened. Two objects are merged key by key when the value of the first object is a plain object; the value of the second object may be a plain object or a class instance (an AxiosHeaders instance merges into the plain headers of the first object). A class instance of the first object is never changed: the value of the second object replaces it, whatever its class, a plain object and an instance of the same class included (a plain object or an https.Agent given as httpsAgent replaces the shared default agent and is not merged into it). The built-in value types are never merged, because their own enumerable keys are not their value: a Date, RegExp, Error, Map, Set, WeakMap, WeakSet, Promise, ArrayBuffer, SharedArrayBuffer, typed array, DataView, Buffer or boxed primitive replaces the other value and is replaced by it. In every other case the value of the second object replaces the value of the first object, whatever the type of either: a scalar replaces an object or an array, an object or an array replaces a scalar (also 0, an empty string, false, null and undefined), null replaces anything, an array replaces an object, an object replaces an array, and a function replaces and is replaced. A key whose value is undefined in the second object is assigned too. Values that are assigned are shared with the second object, not copied.

      Parameters

      • obj1: any

        first object, changed by the merge

      • obj2: any

        second object, merged into the first and not changed

      Returns any

      the first object, with the second object merged into it
