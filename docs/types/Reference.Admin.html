          sub: string,
          scope?: string[],
      ): Promise<AccessTokenResponseType>

      Execute an RFC 7523 JWT-bearer authorization grant: sign a JWT assertion and exchange it for an access token.

      Parameters

      • clientId: string

        client id of the OAuth2 client to request the access token for

      • iss: string

        issuer of the JWT assertion

      • jwk: JwkRsa

        RSA JSON web key that signs the assertion

      • sub: string

        subject of the JWT assertion

      • Optionalscope: string[]

        optional scopes to request (default: fr:am:, fr:idm:, openid)

      Returns Promise<AccessTokenResponseType>

      a promise that resolves to the access token response

    generateRfc7523AuthZGrantArtefacts

    • generateRfc7523AuthZGrantArtefacts(
          clientId: string,
          iss: string,
          jwk?: JwkRsa,
          sub?: string,
          scope?: string[],
          options?: { save: boolean },
      ): Promise<
          {
              client: OAuth2ClientSkeleton;
              issuer: OAuth2TrustedJwtIssuerSkeleton;
              jwk: JwkRsa;
              jwks: JwksInterface;
          },
      >

      Generate the artefacts of an RFC 7523 JWT-bearer authorization grant: a key pair, an OAuth2 client and a trusted JWT issuer. With options.save set, the client and the trusted JWT issuer are also written to the tenant.

      Parameters

      • clientId: string

        client id of the OAuth2 client to generate (the trusted JWT issuer is named after it)

      • iss: string

        issuer of the JWT assertions that the trusted JWT issuer accepts

      • Optionaljwk: JwkRsa

        optional RSA JSON web key to use; a new key is generated when left out

      • Optionalsub: string

        optional subject to put in the allowed subjects of the trusted JWT issuer; the list of allowed subjects is empty when left out

      • Optionalscope: string[]

        optional scopes of the OAuth2 client (default: fr:am:, fr:idm:, openid)

      • Optionaloptions: { save: boolean }

        optional object { save: boolean }; with save true the client and the trusted JWT issuer are created or updated on the tenant (default: { save: false })

      Returns Promise<
          {
              client: OAuth2ClientSkeleton;
              issuer: OAuth2TrustedJwtIssuerSkeleton;
              jwk: JwkRsa;
              jwks: JwksInterface;
          },
      >

      a promise that resolves to an object with the key (jwk), its public key set (jwks), the OAuth2 client (client) and the trusted JWT issuer (issuer)

          },
      >

      Generate the artefacts of RFC 7523 client authentication (private key JWT): a key pair, a client authentication JWT and an OAuth2 client. With options.save set, the client is also written to the tenant.

      Parameters

      • clientId: string

        client id of the OAuth2 client to generate

      • Optionalaud: string

        optional audience of the JWT; the access token URL of the realm when left out

      • Optionaljwk: JwkRsa

        optional RSA JSON web key to use; a new key is generated when left out

      • Optionaloptions: { save: boolean }

        optional object { save: boolean }; with save true the client is created or updated on the tenant (default: { save: false })

      Returns Promise<
          {
              client: OAuth2ClientSkeleton;
              jwk: JwkRsa;
              jwks: JwksInterface;
              jwt: any;
          },
      >

      a promise that resolves to an object with the key (jwk), its public key set (jwks), the client authentication JWT (jwt, signed with that key and valid for 5 minutes) and the OAuth2 client (client)

      • OptionalcustomUsernames: string[]

      • OptionalcustomIPs: string[]

      • OptionalloginsPerUser: number
